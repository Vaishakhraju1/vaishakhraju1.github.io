# Dr Vaishakh Raju — Portfolio

Static portfolio for GitHub Pages, including research projects, engineering automation examples, technical skills, and professional profile links.

## Publish

1. Create a public repository named `vaishakhraju1.github.io` under `Vaishakhraju1`.
2. Upload these files to the root of its `main` branch (extract the ZIP first).
3. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.
4. Wait for GitHub Pages to finish deployment. The website address will be `https://vaishakhraju1.github.io/`.

No package installation or build is needed. The original research scripts and project files are not included.

## Editing

- `index.html`: portfolio content
- `style.css`: styling and responsive layout
- `script.js`: conceptual cantilever visualisation
- `.nojekyll`: serve these files as plain static assets
